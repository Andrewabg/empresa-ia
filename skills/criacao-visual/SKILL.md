# Criação visual

Quando acionada:
1. Busque (`buscarCerebro`) a marca, o tom e o público. Defina o objetivo do criativo (parar o scroll, comunicar oferta, reforçar marca).
2. Para uma IMAGEM: gere com `gerarImagem` um prompt rico (estilo, composição, paleta, mood, formato por canal — feed 1024x1024, story 1024x1536). Itere se preciso.
3. Para um BRIEF/especificação: emita com `emitirArtefato` (`kind: documento`) o brief (conceito, paleta, tipografia, formatos, do/don't da marca).
4. Pense em PERFORMANCE de criativo: hierarquia visual, contraste, legibilidade no mobile, consistência de marca; sugira variações para teste (stop-scroll, CTR do criativo).
5. Na resposta de chat, só RESUMA (a arte/brief está no painel).
